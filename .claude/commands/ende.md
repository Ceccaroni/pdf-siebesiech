---
Session-Ende für PDF-Siebesiech (schlank halten):
1. Aktualisiere **STATUS.md** (Datum, Stand, nächste Schritte, bekannte Grenzen).
2. Verschiebe abgeschlossene Meilensteine aus STATUS.md nach **ARCHIV.md**.
3. Prüfe kurz, dass `npm run build` grün ist (falls Code geändert wurde).
4. Falls Git aktiv: committen (pushen nur auf ausdrücklichen Wunsch).
5. Gib ein 2–3-Zeilen-Fazit.
6. Stoppe laufende Dev-Server.
